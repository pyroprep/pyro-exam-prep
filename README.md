# Pyro Prep Academy — California OSFM Title 19 Exam Prep

Practice questions, detailed explanations, and study tools built directly from CA Title 19 regulations.

**Site:** [https://pyroprep.academy](https://pyroprep.academy)

## Getting Started

First, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Build

```bash
npm run build
```
